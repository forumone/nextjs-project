# Icons

Icons are rendered from a single SVG spritemap (`sprite.artifact.svg`), built
by `lib/generate-icon-sprite.mjs` from the SVGs in the `svgs` directory.
The `Icon` component references a symbol in that sprite by name.

## Adding an icon
To add a new icon:
1. Add the SVG to the `svgs` directory
2. Run either `npm run build-icons` or `ddev frontend icons` to regenerate
   `manifest.ts`, which records each icon's `viewBox` so `Icon` doesn't need
   it passed in manually.
    * If an SVG file has been modified in place without changing the filename,
    then the `force` argument will need to be passed using either:
```
npm run build-icons:force
```
or:
```
ddev frontend icons force
```

Do not modify `manifest.ts` directly. It is overwritten whenever icons are
generated.

## Using icons
Import `Icon` and pass the icon's filename (without the `.svg` extension) as
`name`. TypeScript will only accept names that exist in `manifest.ts`.
<Source language="tsx" type="code" code={
  `
import Icon from '../../01-global/icon/Icon';

function BackToTop({
  text,
  topElement,
  smoothScroll = true,
  modifierClasses,
}: BackToTopProps): JSX.Element {
  return (
    <a
      href="#top"
      className={clsx(styles.link, modifierClasses)}
      title={text}
      aria-hidden={isHidden}
      tabIndex={isHidden ? -1 : undefined}
      onClick={smoothScroll ? handleClick : undefined}
    >
      <Icon name="angle-up" title={text} isHidden={false} />
    </a>
  );
`}/>

To reference an icon dynamically based on a prop or variable, pass that
variable (typed as `IconName`) as `name`.
<Source language='tsx' type='code' code={`
import Icon from './Icon';
import type { IconName } from './manifest';

function LinkedIcon({ iconName, text }: { iconName: IconName; text: string }): JSX.Element {
  return (
    <a href="#">
      <Icon name={iconName} title={text} isHidden={false} />
    </a>
  );
}
`} />
